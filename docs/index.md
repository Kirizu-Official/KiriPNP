# 欢迎

KiriPNP是一个支持全中文的SMT贴片机上位机控制软件，为拾取和放置提供简单易用精准的贴装支持，软件不限制下位机主板，支持大部分3D打印/CNC/GRBL等控制板。目前这是一个非商业用途下的免费软件，欢迎下载体验。

# 开始
请访问 [快速开始](../user-guide/install/start.md)

# 特性

* 支持多个控制板相互协同工作
* 支持基于海康威视工业视觉相机的移动中拍摄(飞拍)
* 支持CANBus总线通信
* 支持CoreXY和传统笛卡尔坐标系
* 支持自动飞达/散料等多种供料方式
