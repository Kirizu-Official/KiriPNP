# 驱动器
控制板所对应的驱动位，在`控制板`选项卡中进行定义
## 反转轴方向
当电机和预期转动方向不同时可通过开关该项目反转电机方向
# 限位开关
在归零过程中使用，当归零过程中限位开关被触发后电机会立即停止运行
## 反转限位信号
默认情况下限位未触发时为高电平(1)，触发后通过限位开关将信号和GND短接拉低信号到低电平(0)，如果实际情况不同可开启该项目后反转信号规则。
# 旋转距离
电机转一圈实际运行的距离
## X/Y/Z轴

### 皮带连接
皮带连接情况下，通常电机是通过联轴器与皮带相连，电机运动一圈的距离取决于：
+ 皮带齿距
+ 传动皮带轮（又称同步轮）
假设同步轮的型号为`20齿内控5`则代表这个同步轮一圈为20齿，如果使用的是`2GT皮带`(即齿距为2mm)，则：
电机一圈运行的距离 = 皮带齿距( 2 mm) x 同步轮齿数(20)  = 40mm
### 丝杠连接
建议问卖家或看详情规格书，一般被称为`导程`，即丝杠将旋转运动转为直线运动时，旋转一圈对应的直线运动距离
### 旋转轴
旋转轴通常电机转一圈为 `360` 度，非特殊情况请直接固定 `360`
